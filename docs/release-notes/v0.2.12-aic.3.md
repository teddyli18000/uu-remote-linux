# AIC v0.2.12-aic.3 (prerelease)

没有插显示器时自动补充虚拟桌面；远程观看按需启停，虚拟屏幕和其中的应用持续运行。

## 行为

- 默认 X11 主机检测物理连接状态，无屏开机或运行中拔掉最后一块物理屏后启动持久 Xvfb 桌面。连接状态未知、锁屏、DPMS 熄屏均不直接当作拔屏。
- 虚拟桌面独立于远程连接。打开远程桌面才编码传输；停止观看保留虚拟屏幕、应用和 PTY，重新插屏也不立即切走。
- 拔屏切换时结束旧桌面连接，重新连接即可看虚拟桌面；独立终端、文件和端口映射连接继续保留。原 PTY 的本机只读窗口移到虚拟桌面，不重启 shell。
- 已存在工具连接稍后请求桌面时，采集、输入、剪贴板和编码使用当前虚拟屏幕。显示切换不重启整个主机服务。
- 显式 `UU_DESKTOP_BACKEND=none/wayland/portal/kms` 或 `UU_AUTO_VIRTUAL_DISPLAY=0` 保留原有行为。

## 运行依赖

Ubuntu 18.04 使用本发布的 `x86_64-ubuntu18.04.tar.gz`。在现有 GTK/VTE/FFmpeg 依赖之外安装：

```sh
sudo apt install xvfb xauth x11-utils dbus-x11 openbox
```

无需安装旧的独立虚拟桌面 service/drop-in。已有固定虚拟桌面配置仍可继续使用。无人登录的开机服务需为运行用户启用 linger。可通过 `UU_VIRTUAL_SIZE` 和 `UU_VIRTUAL_SESSION` 选择尺寸、会话。

Xvfb 是独立的软件 X11 桌面，不能自动迁移实体桌面已打开的任意 GUI 程序，也不提供 GPU 加速。不修改 Ubuntu、ROS、Python、NoMachine 或系统显卡配置。

## 验证范围

GitHub CI 在 Ubuntu 18.04 容器中执行默认构建、单元测试、动态链接检查及真实 Xvfb 桌面验收。物理连接使用可控 DRM 状态夹具模拟，图像来自真实 X11 窗口；检查有屏不补、无屏启动、拔屏补充、重新插屏保留、两次捕获之间屏幕和窗口不变，以及空闲时无编码器。另运行现有 viewer、Wayland/Portal、inproc-av 和 macOS 助手检查。

CI 不能证明具体小车显卡的物理热插拔上报，也不等于本版本已完成官方客户端或车端验收。本发布不自动更新小车。
