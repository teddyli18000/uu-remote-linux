# AIC v0.2.12-aic.4 — 未发布

本版本仍在开发和目标硬件验收前。当前方案保留原 GNOME Xorg 会话，并由受限 helper 运行时强制一个已有 i915 HDMI-A DRM 连接器；不会安装、替换或切换驱动，不修改 Xorg/GDM 配置，也不启动独立桌面。同一 i915 DRM card 有多个 HDMI-A 端口时，按端口号升序选择首个。

helper 计划安装到 `/usr/local/libexec/uuremote-display-helper`，由 root 所有、模式 4750，并仅授权本地图形会话服务用户所在组。仅当所有 DRM 连接器状态都已知且为 disconnected、且目标上只有一个 i915 DRM card 时才允许首次 force-on；绝不选择 DisplayPort。可选 root oneshot 可在显示管理器前执行 `ensure`，为 monitorless boot 准备 HDMI，但 GDM 仍须用机器现有设置启动目标 GNOME 用户会话。状态会在 viewer/host 退出、显示器重插后保持，显式 root `release` 将记录的 connector 恢复到内核自动检测。该受限操作不代表零影响保证，也不保证无 sink 的 HDMI 硬件能提供可捕获扫描画面。同会话热拔屏设计为保留已连接的桌面 viewer，无需用户重连，待目标机验收。

helper 不配置 GDM 自动登录。没有合格 HDMI、状态未知、多 i915 DRM card 或原图形会话未启动时，当前约束下无法提供原桌面补屏。旧版显式 Xvfb 仍是独立桌面，不能继承原 GUI 窗口。

目标 Ubuntu 18.04 / Linux 5.4.0-150 / i915 已完成临时实验：HDMI 拔掉后强制现有端口，原 GNOME 使用内核提供的 1024×768 模式，官方 UU 完整桌面、窗口拖动、键盘输入均正常。独立恢复任务和原样重启 UU 已验证。新版自动热拔屏接管、跨 UU 重启持久性及无屏冷启动仍待验收；dummy CI 仅验证主机控制逻辑和合成输出。未创建本版本 tag 或 GitHub Release，未更新车端。

具体 helper 接口、安装前提和验收步骤见 [SAME_SESSION.md](../../contrib/virtual-desktop/SAME_SESSION.md)。
