# AIC v0.2.12-aic.2 (prerelease)

修复 Windows UU 终端会话列表不更新、终止后条目残留，以及先开终端再开桌面时没有画面的问题。保留 Ubuntu 18.04、系统 GTK/VTE 和现有机器人软件依赖。

## 改动

- 会话创建、重附着、分离和实际退出后发送变化通知，Windows 客户端重新获取列表；终止目标后条目随实际退出移除。
- 本机只读终端窗口点 × 会结束对应 PTY/shell 及其前台进程组，其他会话继续运行；渲染器故障仍只关闭视图。
- 先连终端、后打开桌面时，在已有 peer 上按需启用视频、输入、剪贴板和光标。音频 sender 预先协商，采集等桌面激活后才启动。重复请求幂等，未升级的工具连接不抢桌面输入控制。
- 所有改动均在本项目中，不修改官方 UU 程序。

## 验证与范围

- Ubuntu 18.04 / glibc 2.27 默认 X11 release 测试：193 passed、0 failed、6 ignored；release 构建及对应代码 CI 通过。
- WSL 独立测试设备经 Windows 客户端验收：桌面优先时可同时使用终端，列表刷新与远端终止正常；本机关闭一个终端窗口后对应条目消失，另一个会话继续运行；终端优先时随后打开桌面，画面、鼠标和原终端命令输入正常。
- `UU Remote Terminal` 本机窗口仅作可视化，明确禁用键盘输入；命令从 Windows UU 终端输入。桌面键盘事件已在主机收到并完成 X11 注入，本次未单独验收普通桌面输入框。
- WSL 交互验收使用 CPU H.264、禁用音频；真实音频播放、硬件编码、其他桌面后端及车端环境不由此证明。本发布不自动更新小车。

完整过程见 [Ubuntu 18.04 兼容与验收记录](../ubuntu-18.04.md)。

- `uu-remote-linux-v0.2.12-aic.2-x86_64-linux.tar.gz`：Ubuntu 22.04 构建的主机和实验性 viewer，需要 glibc 2.35 或更新，不能用于 Ubuntu 18.04。
