# AIC v0.2.12-aic.1 (prerelease)

首个 AIC 自用发布，基于上游 v0.2.12 的代码历史。自用开发与发布在 `main`，向上游贡献使用独立分支。

## 包含的改动

- Ubuntu 18.04 / glibc 2.27 构建保留 GTK 登录与 VTE 终端视图。
- 原有远程 PTY 同时显示在本机只读 VTE 窗口；远端控制输入与终端尺寸。
- 补齐终端列表的活动时间字段，按 JSON 目标编号处理会话终止，保留诊断元数据日志。
- 保留上游协议实现、功能和 GPL 授权。此发布不修改官方程序。

## 已知问题

- 官方 Windows 客户端的桌面与终端连接存在冲突反馈，原因尚未确认。
- 终止请求曾确认结束车端 shell，但客户端会话列表仍可能残留，后续新建/环境检测也有异常反馈；不能视为完整修复。
- 本版本用于复现和调试，不作为上述问题已解决的稳定版；发布不自动替换车端或 WSL 正在运行的版本。

## 构建与验证

Ubuntu 18.04 默认 X11、GTK 3.22、VTE 0.52 构建；release 单测 191 passed、0 failed、6 ignored。
既有真实 PTY/VTE 验收覆盖输入输出、窗口恢复与会话生命周期，不能替代官方客户端交互验收。

## 下载

- `uu-remote-linux-v0.2.12-aic.1-x86_64-ubuntu18.04.tar.gz`：兼容 Ubuntu 18.04 的主机 `uuremote-server`，附带文档、LICENSE 和 contrib；不含实验性 viewer。
- `uu-remote-linux-v0.2.12-aic.1-x86_64-linux.tar.gz`：CI 在 Ubuntu 22.04 构建的主机和实验性 viewer，要求 glibc 2.35 或更新，不能用于 Ubuntu 18.04。
- 每个二进制包附带 `.sha256` 校验文件；源码由同名 Git tag 提供。
- 预发布不更新 Docker `latest`，不发布 Docker 镜像。
